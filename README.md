# Transport Tickets — Android

Мобильное приложение для поиска и покупки билетов на транспорт (поезд, самолёт, автобус). Написано полностью на **Kotlin** с использованием **Jetpack Compose**.

## Технологии

| Категория | Инструмент |
|---|---|
| Язык | Kotlin |
| UI | Jetpack Compose, Material3 |
| Навигация | Navigation Compose |
| DI | Hilt |
| Сеть | Retrofit 2, OkHttp, kotlinx.serialization |
| Локальная БД | Room 2.6 |
| Настройки | DataStore Preferences |
| Асинхронность | Kotlin Coroutines + Flow |

## Архитектура

Clean Architecture с тремя слоями:

```
presentation/   — Compose UI + ViewModel (MVVM)
domain/         — Use Cases, модели, интерфейсы репозиториев
data/           — Реализации репозиториев, Room, Retrofit, DataStore
```

## Экраны

| Экран | Описание |
|---|---|
| **Регистрация** | Создание аккаунта по email и паролю |

## Экран поиска

- **Кнопка «Очистить»** отображается только при наличии текста в полях; при нажатии очищает поля и скрывает клавиатуру.
- **Подсказка** в пустом поле ввода («Город отправления», «Город прибытия»).
- **Клавиатура** появляется при нажатии на поле ввода.
- **Сохранение текста** при повороте устройства — состояние хранится в ViewModel.
- **Плейсхолдер «Ничего не найдено»** — если поиск не вернул результатов.
- **Плейсхолдер ошибки** с кнопкой **«Обновить»** — при сетевой ошибке; нажатие повторяет последний запрос.
- **Индикатор загрузки** (скелетон-карточки) во время выполнения запроса.

## История поиска

- Показывается при нажатии на поле ввода (если история непуста и поле пусто).
- Хранится не более **10** записей; новые — сверху.
- При выполнении запроса он автоматически добавляется в историю.
- Кнопка **«Очистить историю»** удаляет все записи.
- История сохраняется в DataStore Preferences между сессиями.

## Тёмная тема

Переключатель тёмной/светлой темы находится в разделе **Профиль**. Выбор сохраняется и применяется при следующем запуске.

## Схемы мест

| Транспорт | Классы |
|---|---|
| Поезд | СВ (2-местное купе), Купе (4-местное), Плацкарт (54 места), Сидячий |
| Самолёт | Бизнес (2+2), Премиум (3+3), Эконом (3+3) |
| Автобус | 4 места в ряду |

